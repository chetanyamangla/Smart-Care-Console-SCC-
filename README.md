# Smart Care Console (SCC)

### An Affordable, Futuristic Assistive System

## About the Project

Smart Care Console (SCC) is an affordable, futuristic assistive system designed to help elderly people and paralyzed individuals perform everyday tasks more independently.

The project brings together different assistive technologies into one integrated platform, with the aim of making everyday life easier, more comfortable and accessible.

## Current Features

### 1. Voice-Controlled Home Automation
Allows users to control household appliances through a voice-controlled application, making everyday operations easier.

### 2. Eye-Blink-Based Control
An assistive control system that allows paralyzed individuals to operate household appliances using eye blinks, without requiring hand movements.

### 3. Smart Medicine Box
A medicine box with preloaded prescriptions to help users organize and manage their medication.

## Future Upgrades

### 2. Wearable Health Monitoring Wristband
A wearable wristband equipped with a heart-rate sensor and accelerometer to monitor basic health and movement-related information.

## Why I Built This

Many elderly and paralyzed individuals face difficulties performing ordinary daily activities independently. I wanted to develop an affordable assistive system that combines multiple useful technologies into one platform rather than relying on separate expensive solutions.

My aim is to make advanced assistive technology more accessible and practical.

## Project Goal

To develop an affordable, integrated and futuristic assistive solution that promotes independence, comfort and accessibility for people who need additional assistance in their daily lives.

## Project Status

The current prototype includes:
- Voice-controlled appliance operation.
- Eye-blink-based appliance control.
- Smart medicine box with preloaded prescriptions.
